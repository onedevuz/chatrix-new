Создание отделов и маршрутизация обращений

Отделы позволяют разделить команду по функциям — продажи, поддержка, бухгалтерия — и автоматически направлять клиентов к нужным специалистам.

Создать отдел

Перейдите в Настройки → Отделы → Создать:

  • Название — например «Продажи», «Поддержка», «Доставка»
  • Операторы — добавьте сотрудников в отдел
  • Расписание — можно задать отдельные рабочие часы для отдела
  • AI-автопилот — включить AI для этого отдела отдельно

Маршрутизация чатов

В Настройки → Маршрутизация задайте правила:

  • По странице — чаты с /pricing идут в «Продажи», с /support в «Поддержку»
  • По UTM-метке — трафик из рекламы направляется к менеджерам продаж
  • По ключевому слову — если клиент написал «возврат» → отдел «Бухгалтерия»
  • Round-robin — чаты распределяются равномерно между операторами отдела

Виджет с выбором отдела

Можно показывать клиенту кнопки выбора отдела при открытии чата:

— Выберите тему обращения:
  [📦 Заказ и доставка]
  [💳 Оплата и возврат]
  [🔧 Техническая помощь]

Настраивается в Настройки → Виджет → Стартовый экран → Кнопки отделов.
